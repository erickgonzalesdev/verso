Verso

Design notes · No build step

Verso is a static webzine starter sitting next to RECTO. Where RECTO is an Astro theme with tokens and two settings, Verso is the opposite edge of the page: classless HTML, one measure, and a title card you can paste.

Stack

  • concrete.css 3.1 — classless base (vendored in css/concrete.min.css)
  • css/theme.css — title cards, feed, features, black field
  • Instrument Serif — title cards, standfirst, poster bands, type on plates
  • IBM Plex Mono — article body (readable column)
  • JetBrains Mono — episode labels, nav, kickers, code

References

  • Neon Genesis Evangelion title cards (series mark stacked; episode left; title right on black)
  • Hermes Agent — centered mark, uppercase mono eyebrows, monumental display, open sections (structure only; field stays black)

Colour

One field: pure black (#000) and near-white type (#f5f5f5). No blue accent, no gray bands between masthead and title card. Tokens live at the top of theme.css.

Run locally

cd verso
npm install
npm run dev
# → http://localhost:4173

Or any static server pointed at this directory.
