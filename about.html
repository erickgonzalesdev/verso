Design notes · Static webzine

Verso is a static webzine starter sitting next to RECTO. Where RECTO is an Astro theme with tokens and two settings, Verso is the opposite edge of the page: classless HTML, one measure, a title card you can paste, and a poster field for issue contents and articles.

Stack

  • concrete.css 3.1 — classless base (vendored in css/concrete.min.css)
  • css/theme.css — title cards, poster field, plate rhythm, black field
  • Geist Sans — sitewide type trial (weight variations only)

References

  • Neon Genesis Evangelion title cards (series mark stacked; episode left; title right on black)
  • Hermes Agent — centered mark, mono eyebrows, open sections (structure only; field stays black)
  • Editorial poster grammar — frame, corner marks, rails, hairline breaks

Colour

One field: pure black (#000) and near-white type (#f5f5f5). No blue accent, no gray bands between masthead and title card. Tokens live at the top of theme.css.

Run locally

cd verso
npm run dev
# → http://localhost:4173

Or any static server pointed at this directory.
