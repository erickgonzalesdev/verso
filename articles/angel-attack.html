Angel Attack

Issue 01 · Sample · 12 min

Every image is a passage. Passages cycle on their own: inset, float right, float left — then the loop starts again. Constant structure, varying frames.

The title card opens the piece. After that, body copy and pictures share one rhythm so no article invents its own layout language. You only write <section class="passage"> around each plate; CSS picks the beat from order.

Intervening paragraphs and headings do not reset the count — only section elements do. Put text that should wrap a float inside .passage__body next to the figure.

Inset → float right → float left → repeat. Same bones every issue. Plate rhythm

After an inset, ordinary copy continues in the measure. The next section.passage will float right — no extra classes required.

Text in passage__body wraps the plate on wide screens. On small screens the plate stacks full-width above the copy. Empty slots are valid — ship the layout before the scan lands.

Keep float bodies short enough that the wrap still reads; if the note is long, use an inset beat instead.

How the cycle works

Among siblings of main.article-body, every section.passage is numbered 1, 2, 3… by CSS :nth-of-type:

  • 1, 4, 7… — inset (block, full measure)
  • 2, 5, 8… — float right
  • 3, 6, 9… — float left

Third passage of the cycle. After this, the next section is inset again — the loop is the whole framework.

Second cycle

Same markup, new pictures. The framework does not care what the frames show — only their order.

Second float-right of the piece. Vary crop and content; keep the skeleton identical.

End of the second cycle. Add more passages as the piece needs; they keep stepping through the same three beats.

Escapes

When the rhythm must break, say so on the section: passage--inset, passage--float-right, passage--float-left. For a wider block that stays out of the float cycle, use passage--span or passage--fill (always block). Equal text/image columns use .pair outside the passage sequence.

Note: a span escape is still a section, so it advances the nth-of-type counter. Prefer keeping escapes rare, or place them with awareness of the next beat. 

<section class="passage">
  <figure class="plate">
    <div class="plate__frame" style="aspect-ratio: 3 / 2">
      <img src="…" alt="…" />
    </div>
    <figcaption>Caption</figcaption>
  </figure>
  <!-- float beats: optional wrapping copy -->
  <div class="passage__body">
    <p>…</p>
  </div>
</section>
