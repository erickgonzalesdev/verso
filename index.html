Verso Issue One

Episode : 01

First Contact

A classless webzine starter

Built on concrete.css, with title cards cut from Neon Genesis Evangelion and layout grammar from Hermes — centered mark, mono eyebrows, monumental type — on a single black field. Semantic HTML first; almost no classes required for body copy.

Read the sample   How it works

This issue

  • Episode : 01 Angel Attack A sample piece demonstrating the title card, byline, and drop cap on concrete’s measure.
  • Episode : 02 The Beast Poster scroll, refined — one column, freeform plates, type under images.
  • Episode : 03 A Transfer Stub entry — replace with your third article.

What you get

  • #1 Base

    Concrete

    Classless CSS: JetBrains Mono body, square bullets, ~640px measure. Drop in HTML and it already looks finished.

  • #2 Titles

    Title cards

    Stacked display type, mono episode labels split left and right — the NGE card as a reusable pattern on the same black field.

  • #3 Chrome

    Hermes notes

    Centered wordmark, uppercase mono eyebrows, wide tracking, open feature blocks — Hermes structure without the blue.

  • #4 Form

    Starter pages

    Home, article, and about. Copy a card, rename an episode, ship an issue before the photographs arrive.
